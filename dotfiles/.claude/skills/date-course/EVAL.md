# date-course 스킬 평가 하네스 (EVAL)

스킬을 고칠 때마다 이 문서의 시나리오·루브릭으로 재평가하고 점수를 갱신한다.
최근 평가: **2026-07-19** (실제 카카오 키·실검색·WebSearch로 엔드투엔드 수행).

## 루브릭 (항목당 0/1/2점)

| 축 | 2점 기준 |
|---|---|
| ① 실재성 | 모든 가게가 카카오 실검색 결과 + 2024년 이후 언급 확인, 폐업 신호 없음 |
| ② 동선 | `route_util.py` 계산값 사용, backtracking 없음, 대중교통 구간 시간 명시 |
| ③ 시간 배분 | 체류+이동 합계가 요청 시간 ±15분 |
| ④ 원칙 반영 | 🎯피크·🏁피날레 배치 근거 타당, 정·동 완급 교차, 취향 충족 |
| ⑤ 출력 품질 | 형식(동선요약·비용·Plan B·예약 안내) 완비, 스캔 가능 |

**합격선:** 시나리오 평균 ≥ 1.5 **그리고** ①실재성 = 2 (허위/폐업 가게 하나라도 있으면 fail).

## 시나리오 및 채점 (2026-07-19, 1차)

### S1 기본 — "성수동 오후 2시부터 4시간, 감성 카페 위주"
코스: 클레멘타인(카페) → 내러티브 오브젝트(소품샵) → 더서울라이티움(전시 🎯) → 서울숲(🏁)
- 동선: route_util 총 도보 14분, 한 방향(서울숲 클러스터), 전 구간 도보.
- 근거: 클레멘타인 [2025.5 방문 후기](https://kr.trip.com/moments/detail/seoul-234-132233761/), 내러티브 오브젝트 [2025 마리끌레르](https://www.marieclairekorea.com/culture/lifestyle/2025/08/living-shop-map/) (화~일 12-18시, 월휴무), 라이티움 화~일 10-19시 — 당일 전시 일정은 별도 확인 필요로 표기.
- **점수: ①2 ②2 ③2 ④2 ⑤2 = 평균 2.0 PASS**

### S2 타이밍·피크엔드 — "연남동 저녁 데이트, 야경으로 마무리"
코스: 소이연남(저녁, 웨이팅 주의) → 경의선숲길 산책(일몰 ~19:50 타이밍) → 뮬 연남(와인 🏁)
- 규칙 작동 확인: 1차 피날레 후보 '문릿아워'(카카오엔 존재)는 **2024+ 웹 언급 확인 실패 → 제외** → 뮬 연남([2025.9 리뷰](https://polle.com/hyeonsi709/posts/6), 디너 예약 필수)로 교체.
- 감점: **연남동엔 야경 스팟이 사실상 없음** — "야경" 취향을 노을+와인으로 대체할 수밖에 없는데, 지역-취향 불일치를 솔직히 알리는 가이드가 SKILL.md에 없음.
- **점수: ①2 ②2 ③2 ④1 ⑤2 = 평균 1.8 PASS**

### S3 악천후 — "주말 비 예보, 잠실 실내 위주"
코스: 갓덴스시 롯데월드몰(점심) → 롯데월드 아쿠아리움(🎯 몰입형) → 몰 내 카페 → 서울스카이(🏁 실내 전망)
- 예보 실확인: 기상청 중기예보 "수도권 25일(토)까지 비" → 전 구간 한 건물(올림픽로 300), 우천 노출 0.
- **점수: ①2 ②2 ③2 ④2 ⑤2 = 평균 2.0 PASS**

### S4 데이터 희소성 — "대전 은행동 오후 데이트"
코스: 대전근현대사전시관 → 산호초(카페) → 성심당 본점(빵) → 목척교·대전천 산책(🏁)
- 지방 후보 풀 충분(카페 964건·음식점 3,720건) — 희소성 우려는 서울 밖 광역시에선 기우.
- 규칙 작동 확인 ×2: '데이즈'는 2024+ 언급 확인 실패 → 교체. 웹 추천 '노마드오븐'은 **카카오에 없음 → 교차 확인 규칙이 제외** (웹의 낡은 정보 차단). 산호초는 카카오 + [2025 트립닷컴](https://kr.trip.com/moments/detail/daejeon-21419-136999123/) 모두 확인.
- 동선: route_util 총 도보 16분, 서→동→북 한 방향.
- 감점: 몰입형 활동(방탈출 등) 미포함, 흥분전이 원칙 미적용.
- **점수: ①2 ②2 ③2 ④1 ⑤2 = 평균 1.8 PASS**

**1차 종합: 4/4 시나리오 합격, 전 시나리오 실재성 2점.**

## 1차 평가에서 확정된 결함 — **전부 수정 완료 (2026-07-19)**

1. ✅ **[코드] `route_util.py` 총합에서 대중교통 구간 누락** — 1.7km 구간(21분)이 있는 코스가 "총 도보 7분"으로 표시됐음. **수정**: 대중교통 구간 추정치(오버헤드 10분 + 직선거리/500m/분) 추가, `총 이동 = 도보 + 대중교통 추정`으로 출력, 분 반올림은 합산 후 1회. 재검증: 같은 코스가 "총 이동 약 20분 = 도보 7분 + 대중교통 약 13분"으로 출력됨.
2. ✅ **[프롬프트] 검색어 0건 함정** — `연남동 저녁 맛집` → 0건. **수정**: SKILL.md 검색어 규칙을 "단순 명사형 + 0건 시 수식어 제거 재검색" fallback으로 교체.
3. ✅ **[프롬프트] 최신성 검증의 현실 보정** — 소규모 가게는 영업 중이어도 검색에 안 걸림(문릿아워·데이즈). **수정**: 위험도 기반 규칙으로 교체(폐업 신호=제외 / 언급 없음=교체 또는 "영업 확인 권장" 표기 / 체인·공공시설=생략 가능) + 웹 발견 후보의 카카오 교차 확인 의무화.
4. ✅ **[프롬프트] 지역-취향 불일치 처리 부재** — **수정**: SKILL.md에 "억지로 끼워 맞추지 말고 솔직히 알린 뒤 대안 제시 + 지역 확장 질문" 규칙 추가.

## 알려진 한계 (수정 불가/보류)
- 카카오 keyword API는 **영업시간·휴무를 안 줌** → WebSearch 의존, 출력에 "방문 전 재확인" 필수 문구 유지.
- 도보시간은 haversine×1.3 추정치(실제 도로/신호 미반영) — 카카오맵 대조 결과 ±20% 내로 실용적.
- WebSearch는 US 기반이라 네이버 블로그 결과가 약함 — 트립닷컴/다이닝코드/인스타로 보완됨.
